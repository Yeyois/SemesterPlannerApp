# SemesterPlanner 🎓⏳

**SemesterPlanner** is an Android application designed to help working students effectively balance their academic degree courses with employment schedules and weekly workloads.

---

## ✨ Features

- **Semester Course Distribution:** Organize, schedule, and distribute degree requirements across semesters.
- **Workload Management:** Track course credit hours, study commitments, and working hours side-by-side to prevent burnout.
- **Prerequisite Tracking:** Visualize and manage course dependencies to build an optimal graduation roadmap.
- **Modern Android UI:** Fully built with modern declarative UI using Jetpack Compose and Material 3 design standards.

---

## 🛠 Tech Stack

- **Platform:** Android
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Architecture:** MVVM (Model-View-ViewModel)
- **Build System:** Gradle (Kotlin DSL)
